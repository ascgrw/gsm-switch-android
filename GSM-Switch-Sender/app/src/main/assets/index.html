User guide

Quick start
  1. Open the side menu, then Settings. Enable SMS and choose the SIM you want to send from.
  2. Tap Add switch. Enter a name, controller number with country code, output and the device’s 6–12 digit PIN.
  3. Choose the auto-off time for output 1, then save.
  4. Tap the single power button to alternate ON and OFF. It shows ON with a blue glow after an ON SMS is sent and shows OFF dimmed after an OFF SMS is sent. Tap a glowing ON button to send OFF; tap a dimmed OFF button to send ON. A button with no known state says Power. The app sends the SMS automatically. Read controller replies in your phone’s Messages app.
Add, edit and remove switches

Use the edit icon on a card to rename a switch, change its controller number, output or timer, or remove it. Removing a card does not send an OFF command.

Choose Original for existing two-output firmware. Choose Updated only after flashing the included four-output firmware. Empty tiles add the remaining outputs for that controller. Up to 30 controllers and 120 switches are supported; each number/output pair can be added only once.

Outputs on one controller share its PIN. Leave the PIN blank when editing to keep a saved PIN.

Timers and outputs

Output 1 turns off automatically after its selected timer. The app offers 30 seconds to 15 minutes; existing backups can retain a timer from 1–900 seconds.

Outputs 2, 3 and 4 stay on until you send OFF. A timer that has elapsed makes the app’s state unknown; it cannot check whether the controller received the command. Renaming a button does not change what it does.

All controls and status

All ON and All OFF send commands to the outputs you added. Individual commands are used when any output is unassigned, so empty slots are not switched. ALL is used only when every output of the chosen firmware is assigned.

Status asks each saved controller to reply by SMS. Read the reply in Messages. The glow shows the last successfully sent command, not a confirmed physical state. “Sending” does not change the state; failed SMS keeps the previous sent state. If Android gives no sending result for two minutes, state becomes unknown and the button is available again. Read actual relay reports in Messages. After a controller restart or an outside command, the app’s last sent state can be outdated.

SMS permission and SIM

Allow Send SMS in Settings. Commands are sent only when you tap a control. Your mobile plan’s SMS charges apply.

For dual-SIM phones, change the sending SIM in Settings. SIM selection can request Phone permission. If you decline, choose a default SMS SIM in your phone’s settings.

This sender app does not read incoming SMS. Controller replies stay in Messages. The device PIN is included in each outgoing command and may remain in the phone’s message history.

Test with another mobile phone

Add the other phone’s number as a test controller and use a test PIN. Tap a control and check the received SMS on that phone. This checks sending and command format; it does not test relay operation.

Commands have the format PIN REQUEST_ID COMMAND, for example 654321 A1B2C3D4 R1 ON 300. Actual controllers must use matching firmware and PINs.

Backup and restore

In Settings, Backup saves your switches, activity, app name and custom labels. Restore replaces switches and activity with the selected backup after confirmation. Older backups are supported.

PINs are encrypted on the phone and excluded from backups. Re-enter them after reinstalling or moving to a new phone. Activity can also be exported separately.

Personalize names and labels

Use the card’s edit icon to rename a switch. In the side menu, App name changes the name inside the app and Recent apps. The phone’s launcher label is GSM Switch Navy.

Edit labels changes button, menu and form wording. ON and OFF labels must differ. Display labels never change the actual SMS commands. Restore defaults resets the wording when you save.

Troubleshooting and updates

If SMS fails, check permission, the selected SIM, phone number, signal and available SMS credit. The app does not retry automatically.

If a message sends but the controller does not respond, check its power, SIM signal, firmware and PIN. Read replies in Messages.

Version 1.7 uses the same signing key as 1.4–1.6 and can update them. After installation, open GSM Switch Navy and check the v1.7 badge. Versions 1.3 and earlier used another key: back up first, uninstall the earlier sender, install this app, then restore and re-enter your PINs.

Wiring

R1: D1 / GPIO5 (timed). R2: D2 / GPIO4. R3: D0 / GPIO16. R4: D7 / GPIO13. R3 and R4 require the included four-output firmware and two additional active-HIGH relay drivers. All outputs start OFF after reset. Use a transistor/MOSFET driver with flyback protection and a gate pulldown for each relay, never a bare relay coil on a GPIO. The existing diagram shows the original two drivers; repeat that driver circuit for R3 and R4. D5/D6 are reserved for the GSM serial connection; boot and flash pins are not available as extra relay outputs.
